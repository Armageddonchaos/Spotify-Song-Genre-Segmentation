# Spotify Songs' Genre Segmentation

## Project Overview
This project uses Machine Learning to group
Spotify songs based on their audio features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
K-Means Clustering

## Dataset
Spotify Songs Dataset (32,833 records originally).

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Correlation Analysis
5. Feature Scaling
6. K-Means Clustering
7. Model Evaluation
8. PCA Visualization
9. Song Recommendation

## Results
The model groups songs into clusters based
on their audio characteristics.
